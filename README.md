# Kastrat — Kajian & Aksi Strategis (Frontend)

Simple Vite + React + Tailwind starter for the Kastrat site (BEM FTI).

Quick start

```bash
npm install
npm run dev
```

Notes
- UI built with React functional components and Tailwind CSS.
- Icons: lucide-react.
- State: React Context (see `src/context/StudiesContext.jsx`).
